# Plano de Estudo — Teoria dos Grafos (Prof. Tenório)

Guia completo de Teoria dos Grafos, do zero ao avançado. Criado para a prova do Prof. Tenório.

## Conteúdo

- 17 tópicos da prova com exemplos e grafos visuais (SVG)
- Matrizes de adjacência interativas
- 20 questões fechadas interativas (selecione e responda)
- 30 questões abertas com gabarito comentado
- Tutorial de complexidade algorítmica (Big-O)

## Como rodar localmente

```bash
# Basta abrir o arquivo HTML diretamente no browser
# Ou instalar serve para uma experiência de servidor:
npm install -g serve
serve .
```

## Deploy no Vercel

1. Faça push para o GitHub
2. Acesse [vercel.com](https://vercel.com)
3. Importe o repositório
4. Deploy automático!
